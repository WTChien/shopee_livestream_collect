# shopee_livestream_collect

## 啟動本機介面

Windows 雙擊 `start.bat`，或在專案目錄執行 `./start.bat`。程式會在本機 `127.0.0.1` 啟動並開啟瀏覽器；若 4001 埠已占用，會自動改用空閒埠。關閉啟動視窗即可停止服務。

面板可查看 ADB 裝置、啟停單台機器人、擷取手機畫面、測試蝦幣 OCR、標記卡片範圍和按鈕位置，以及查看今日與歷史領取紀錄。定位操作只儲存座標，不會直接點擊手機。

裝置卡片上的「啟動」與 LINE `/啟動 裝置名稱` 使用同一流程：主畫面會開啟蝦皮並進直播；已在直播且藍色蝦幣卡片可辨識時會直接接續；蝦皮畫面沒有可辨識藍卡時會先關閉蝦皮、回主畫面，再重新進直播。皮克敏等其他 App 在前景時不會啟動。

## LINE 查詢進度

傳送 `/指令` 可列出所有 LINE 指令與簡短說明。

在已綁定的群組輸入 `/畫面 A8+`，Bot 會擷取該手機當下畫面並回覆圖片。圖片只暫存在 LINE webhook 的記憶體中供 LINE 讀取，10 分鐘後移除，不會寫入磁碟。公開圖片網址使用 `LINE_PUBLIC_BASE_URL`（預設 `https://shopeeline.weiting.win`），只暴露隨機網址的單張圖片，不公開 4001 工作台。

`/重啟 A8+` 只接受正在刷取的手機，會關閉蝦皮、回到主畫面，再重新進入直播並繼續刷取。手機已切換到其他 App 時不會覆蓋當前畫面；每日排程執行中也不接受此指令。

LINE 可傳送 `/狀態`，查看目前已連線手機顯示的 App、是否刷取中，自動流程進度、今日點擊次數與蝦幣。`/啟動 A8+` 會依 `devices.json` 的自訂名稱找手機。若手機已在蝦皮直播畫面且能辨識藍色蝦幣卡片，正在刷取就維持原流程，未刷取則直接從當前畫面接續。其他允許啟動的情況會先關閉蝦皮、回到主畫面，再重新開啟蝦皮、進入直播並開始刷取。若前景是皮克敏或其他 App、無法判斷前景、已達每日上限或處於暫停時段，會回覆原因且不啟動。執行中若切換到其他 App，流程會在下一輪檢查時停止。`/停止 A8+` 可停止該台手機的流程。`/啟動` 與 `/停止` 只能在已用 `/綁定 密碼` 綁定的群組使用；若要在私人聊天控制，需在 `line.env` 設定 `LINE_CONTROL_USER_ID`。修改設定後請重新啟動工作台與 LINE webhook。

可沿用現有 LINE Messaging API 頻道。在一對一聊天或有加入機器人的群組傳送 `/狀態`，會回覆每台已連線手機是否刷取中、今日點擊次數、所得蝦幣及今日合計。任何與機器人對話的 LINE 帳號或群組成員都能查詢這些資料。LINE webhook 使用獨立服務 `line_webhook.py`（本機 `127.0.0.1:4002`）；不要把工作台 `4001` 埠接到公開網域。

裝置停止提醒只會主動傳到一個已綁定的群組，不會主動傳到私人聊天。在要接收通知的群組輸入 `/綁定 密碼`；收到成功回覆後，手動停止、達到上限、排程結束或切換到其他 App 而停止時，都會送出裝置與停止原因。於該群組輸入 `/解除綁定 密碼` 即可關閉提醒。若改在其他群組綁定，通知目的地會改成新群組。密碼存於本機 `line.env` 的 `LINE_GROUP_BIND_CODE`，群組 ID 存於 `data/line_notification_group.json`，兩者都不會提交到 Git。`/狀態` 查詢不需綁定。

正在刷取的手機進入每日暫停時段時，已綁定群組會收到一次暫停通知與預計恢復時間；原本就在暫停時段內才啟動的流程不會重複通知。執行中若確認蝦皮回到桌面，群組也會收到疑似閃退與自動重啟提醒；10 分鐘內連續回到桌面時會暫緩 60 秒再重試，直到使用者手動停止。可在「手機畫面定位」為每台手機標記切換直播的滑動起點、終點和毫秒時間；在滑動模式按「儲存目前標記」或下方的「儲存這台手機的滑動」都會保存滑動設定，切回裝置時會重新載入截圖與標記；未設定時 A8+ 使用較長滑動距離與 250 毫秒，其他手機維持原有速度。

1. 複製 `line.env.example` 為 `line.env`。從 LINE Developers 的 Basic settings 取得 Channel secret，從 Messaging API 取得 Channel access token，並設定 `LINE_GROUP_BIND_CODE`，填入本機檔案。`line.env` 已排除於 Git。
2. 在 Cloudflare 建立固定的 Tunnel，將 `shopeeline.weiting.win` 的 HTTP 服務指向 `http://127.0.0.1:4002`，並把連接器權杖填入 `line.env` 的 `CLOUDFLARE_TUNNEL_TOKEN`。LINE Developers 的 Webhook URL 設為 `https://shopeeline.weiting.win/webhook`，開啟 Use webhook，按 Verify 測試。
3. 在 PowerShell 執行 `./start-line.ps1`，或使用 `start.bat` 同時啟動工作台與 LINE 服務。兩者都需要保持執行。
4. 在一對一聊天或群組傳送 `/狀態` 即可查詢，無須綁定。

本機電腦、工作台、LINE webhook 與 Cloudflare Tunnel 都必須保持執行。若 Tunnel 尚未安裝，可依 [Cloudflare 官方說明](https://developers.cloudflare.com/tunnel/get-started/create-remote-tunnel/)建立；LINE webhook 必須是公開 HTTPS 網址，並須驗證 LINE 簽章。成功提示未讀到時，所得會按卡片金額估算並在 LINE 回覆中註明。

「每日自動執行」可設定手機、台灣時間與完成條件。已替 `5200f803b437b41f` 建立 Windows 每天 **08:00** 的工作排程；此工作由 `daily_run.py` 獨立執行，關閉瀏覽器或工作台視窗後仍會在指定時間啟動。電腦需開機並登入 Windows、手機保持 ADB 連線。目前完成條件設定為當天達到每日上限（預設 **90 次**），此模式不受無新領取時間或最長運行時間限制；也可在介面改成一段時間無新領取後結束。結束時會透過 ADB 關閉蝦皮並返回手機首頁。首頁廣告會先關閉，再點「直播短影音」入口；若進入「推薦」分頁，會點上方「直播」並確認底線位於「直播」下方。若無法自動找到首頁入口，可在手機畫面定位中標記「蝦皮首頁直播入口」。網頁也有「開啟蝦皮並進直播」與「關閉蝦皮」按鈕可手動測試。

scrcpy 的 `Alt+S` 是開啟 Android 最近使用的 App 清單；本專案以 ADB `am force-stop com.shopee.tw` 關閉蝦皮，不依賴 scrcpy 視窗。每日排程、執行狀態與日誌分別保存在 `data/daily_schedule.json`、`data/daily_status/` 與 `data/schedule_logs/`。

## Windows 開發環境

在專案根目錄建立虛擬環境並安裝依賴：

```powershell
uv venv --python 3.14 .venv
uv pip install --python .\.venv\Scripts\python.exe -r requirements.txt
```

EasyOCR 已列在 `requirements.txt`。直播間右上角蝦幣卡片使用 EasyOCR；直播列表的金額挑選仍使用 RapidOCR。

此開發環境已將繁體中文與英文模型下載到 `.easyocr/model/`。使用時指定相同路徑即可離線載入：

```python
from pathlib import Path
import easyocr

model_dir = Path(__file__).resolve().parent / ".easyocr" / "model"
reader = easyocr.Reader(
    ["ch_tra", "en"],
    gpu=False,
    model_storage_directory=str(model_dir),
    download_enabled=False,
)
```

模型檔及虛擬環境已由 `.gitignore` 排除；其他機器需自行下載模型。

## 每台手機的蝦幣卡片座標

在「手機畫面定位」可新增例外畫面（例如點歪進入商品頁）：先擷取該畫面，輸入名稱，選「例外畫面特徵框」拖曳 1–3 個固定的文字或圖示區塊，再選擇按手機返回鍵，或以「例外畫面關閉位置」點選畫面上的叉叉，最後按「儲存例外畫面」。可儲存多個畫面、測試辨識及逐一刪除。系統只保存特徵小圖與座標，不保存整張截圖；刷取時辨識到例外畫面會先執行返回動作，仍無法恢復時會間隔重試，直到使用者手動停止。

`reward_vision.py` 會在畫面右上角動態找出藍色蝦幣卡片，只在藍色區塊讀取金額、倒數與橘色領取按鈕。上方紅色區塊的倒數獨立讀取並顯示於日誌，不會阻止藍色卡片領取，也不會用來決定是否切換直播間。藍色狀態不明時會等待下一張畫面。

每台手機首次確認卡片後會建立 `device_regions/<ADB序號>.json`，儲存當時的螢幕大小及藍色卡片矩形；原有 `reward_box` 與 `coin_center` 繼續保留。可另外儲存 `red_box`、`blue_box` 手動框選範圍。例如 [測試手機的座標](device_regions/5200f803b437b41f.json)。未手動框選時，程式每次重新從畫面定位藍色區塊。

在面板中可拖曳紅色區塊、藍色區塊及成功提示範圍，或點選「直播分頁」「彈窗關閉」標記中心，再按「儲存座標」。藍色倒數與蝦幣金額直接從藍色區域辨識，蝦幣圓心由程式推算，不需另外框選或點選。手動設定會寫入同一台手機的 JSON。每次辨識會在選定的藍色區域內使用 EasyOCR 尋找「領取」文字，將文字框中心換算成手機畫面座標作為點擊位置；「測試辨識」會顯示並標出此中心點。找不到文字或金額時不點擊。

要移除單一定位，先選擇對應的藍色區塊、紅色區塊、成功提示範圍或按鈕標記，再按「清除目前選取的標記」；變更會立即儲存，其他標記保留。清除藍色區塊後恢復自動定位。

遇到橘色「馬上簽到／領蝦幣或抽優惠券」彈窗時，程式會先辨識文字與橘色區塊，再定位下方圓形叉叉並關閉。若自動定位不準，可在面板選「簽到彈窗叉叉」標記該手機的位置；此位置只在辨識到簽到彈窗後使用。

## 領取紀錄與每日上限

系統設定預設啟用台灣時間 **23:30～隔日 00:30** 的每日暫停時段。工作台服務執行期間會定期關閉所有已連接手機的蝦皮；執行中的採集流程暫停，時段結束再自動開啟直播。每日排程即使在時段內啟動也會先等待。暫停時間不計入最長運行或無新領取的分鐘數。可在面板修改時間或停用此規則。

逐筆紀錄儲存在 `data/claims.sqlite3`，以台灣日期統計。「系統設定」可調整所有裝置共用的每日點擊上限（預設每台 **90 次**）、重新讀取間隔（預設 **5 秒**）、最低蝦幣（預設 **0.30**）、連續無卡片直播間數（預設 **20 間**）、連續顯示限制門檻（預設 **5 間**）、直播分頁刷新間隔（預設 **30 分鐘**）及點擊後等待成功提示時間（預設 **8 秒**）。點擊領取後會計入每日名額；到達上限後不再自動領取。卡片倒數與讀取失敗時會依設定的間隔重讀；實際間隔還包含 OCR 和手機操作所需時間。低於最低蝦幣會略過該直播間。連續指定間數都沒有藍色卡片時，會關閉蝦皮並停止該裝置的採集流程；看到藍色卡片就重新計數。點擊領取後，若 OCR 讀到「成功領取 X Coins」，會以提示金額計入所得；若未讀到成功提示，則自動以點擊前辨識的卡片金額計入，並在紀錄中標示為「自動計入（卡片金額）」。流程會略過該直播間繼續執行。手動補記可輸入過去日期與金額，錯誤紀錄可刪除。

歷史表顯示已確認紀錄的每日與總計金額。原有 `collect_log.csv` 是執行摘要，沒有逐筆金額，無法自動還原舊資料；若要納入舊紀錄，需從面板手動補記。資料庫已被 `.gitignore` 排除，備份時請一併保存 `data/claims.sqlite3`。
